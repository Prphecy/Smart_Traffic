SmartTraffic MVC

Sistema inteligente de tráfico basado en grafos, recorridos BFS/DFS y estructuras de datos en Java.

Ver Mapa Ejecutar Algoritmos

Modelo

Las clases Ciudad y Ruta representan los datos principales del sistema.

Vista

Las páginas HTML con Thymeleaf muestran el mapa, las rutas y los recorridos.

Controlador

Los controladores reciben las solicitudes del usuario y envían datos a las vistas.
